# WuxiaIdle 古典武侠放置游戏

> **核心设定**：低武/中武世界，拳拳到肉的古典武侠，类似金庸、古龙小说中的江湖设定。无仙术、无法术、无飞天遁地。

## 项目简介

WuxiaIdle 是一款基于 Vue 3 + TypeScript 构建的古典武侠题材文字放置类游戏。游戏以明朝中叶的江湖为背景，玩家扮演一名孤儿，自幼被老拳师收养，十八岁那年得知父亲死于二十年前的一场惊天阴谋，从此踏上江湖，追寻真相。

游戏采用极简的黑白灰界面设计，专为「上班摸鱼」场景优化，以文字描述为核心营造武侠小说的阅读感。本项目采用本地存储方案（localStorage）作为数据持久化手段，遵循 KISS 设计原则，强调代码简洁性和可维护性。

### 核心冲突

二十年前，江南首富「金枪」沈百万举办「天下第一武道会」，邀请天下高手比武夺魁。然而比赛进行到一半时，沈百万突然暴毙，七位顶尖高手遭遇伏击，六人当场身亡，只有一人重伤逃脱——武当派大弟子，后来的武当掌门清虚子。

你的父亲，就是当年死在沈府的六位高手之一。老拳师临终前只留下一句话：「去江湖看看，找到那个杀害你父亲的人。」你要做的，只有三个字：找真相。

## 核心特性

### 江湖格局

武林中形成了以少林、武当、峨眉、华山、丐帮五大派为尊的格局：

| 门派     | 武学风格 | 代表武功             | 装备特色             | 门派定位 |
| -------- | -------- | -------------------- | -------------------- | -------- |
| **少林** | 刚猛霸道 | 易筋经、金刚掌       | 僧袍、禅杖、铜环手套 | 前排肉盾 |
| **武当** | 以柔克刚 | 太极拳、真武剑       | 道袍、拂尘、太极剑   | 控制续航 |
| **峨眉** | 灵动飘逸 | 灭剑术、回风拂柳剑   | 女侠装、峨眉刺       | 爆发输出 |
| **华山** | 奇险快绝 | 独孤九剑、紫霞神功   | 华服、君子剑、面具   | 核心输出 |
| **丐帮** | 刚猛凌厉 | 降龙十八掌、打狗棒法 | 丐衣、酒葫芦、打狗棒 | 辅助增益 |

五大派之间存在克制关系：少林→武当→峨眉→华山→丐帮→少林，克制方对被克制方有 10% 伤害加成。

### 主线叙事：「真相之路」

游戏围绕「真相之路」主线展开，分为五个阶段，每个阶段都有明确的目标和奖励：

| 阶段         | 游戏时间   | 核心目标             | 解锁内容           |
| ------------ | ---------- | -------------------- | ------------------ |
| **初入江湖** | 第1-7天    | 加入门派，学会武功   | 玄榜挑战资格       |
| **小有所成** | 第8-30天   | 挑战江湖榜，收集线索 | 高级副本、地榜挑战 |
| **名动江湖** | 第31-90天  | 查明真相，提升地位   | 天榜挑战、门派禁地 |
| **风云际会** | 第91-150天 | 参与武林大会         | 终极副本、最终剧情 |
| **真相大白** | 第151天+   | 做出最终选择         | 多结局、江湖重建   |

### 功能模块

**战斗系统**：江湖榜挑战、门派挑战、生死状、副本探索。战斗采用自动回合制，伤害计算遵循「攻击力 × 技能系数 - 防御减免」的经典公式。

**装备系统**：兵器谱排名记录江湖上最好的十件兵器，分为剑谱、刀谱、枪谱、棍谱、暗器谱五个分类。装备可锻造提升品质，可附带词缀提供额外属性加成。

**生活技能**：采集技能（采药、伐木、采矿、钓鱼、狩猎）产出原材料，制造技能（锻造、制皮、炼丹、烹饪）加工为成品。生活技能与主线紧密关联——锻造产出兵器、炼丹产出药品支持战斗和副本。

**闭关修炼**：内功修炼消耗「修炼时间」获得「内功经验」，境界分为「入门」、「小成」、「大成」、「圆满」四个层次。不同门派有不同的内功心法，修炼后可获得独特的内功技能。

**护镖系统**：护镖任务将货物从一地运送到另一地，过程中触发随机事件（平安、劫匪、损耗、意外之财、休整）。护镖是江湖恩怨的高发地带，也是获取金币和声望的重要途径。

**任务系统**：日常任务、周常任务、门派任务、成就系统记录玩家在游戏中的各种「第一次」和「最高记录」，是玩家成长的指南针。

**地点系统**：游戏中共有二十七个地点，形成完整的江湖版图，包括新手村、城镇、野外的门派所在地、副本入口和与主线相关的特殊地点。

### 江湖声望与门派系统

江湖声望是衡量玩家江湖地位的重要指标，共分八个等级：

| 等级 | 名称       | 声望值      | 解锁内容         |
| ---- | ---------- | ----------- | ---------------- |
| 1    | 无名小卒   | 0-99        | 基础功能开放     |
| 2    | 江湖新秀   | 100-499     | 玄榜挑战资格     |
| 3    | 小有名气   | 500-1499    | 高级副本入口     |
| 4    | 一流高手   | 1500-4999   | 地榜挑战资格     |
| 5    | 赫赫有名   | 5000-14999  | 门派高层任务     |
| 6    | 宗师级人物 | 15000-49999 | 天榜挑战资格     |
| 7    | 武林泰斗   | 50000-99999 | 武林大会参赛资格 |
| 8    | 传奇人物   | 100000+     | 终极剧情解锁     |

门派贡献衡量弟子对门派的贡献程度，可兑换门派制式装备、武功卷轴、突破丹药等。门派声望与江湖声望平行存在，两者相互影响但不完全等同。

| 乾坤大挪移 | 悟道闭关     | 闪避率+15%               |
| 六脉神剑   | 武林大会     | 暴击率+20%，暴击伤害+50% |
| 易筋经     | 炼体闭关     | 生命上限+30%             |
| 小无相功   | 收集残篇     | 装备技能冷却-25%         |
| 独孤九剑   | 击败剑道高手 | 破甲+20%                 |
| 九阴真经   | 集齐3块令牌  | 全技能等级+1             |
| 太玄经     | 完成隐藏任务 | 离线收益+100%            |

## 技术架构

### 核心技术栈

前端框架选用 Vue 3 搭配 Composition API，状态管理优先使用 Vue 3 原生响应式系统，必要时引入 Pinia。UI 组件优先采用原生 HTML/CSS 实现，避免引入复杂的第三方 UI 库。构建工具使用 Vite，配合 TypeScript 提供完整的类型安全保障。数据持久化采用 localStorage 实现。

### 项目结构

```
src/
├── components/          # 可复用组件
│   ├── ui/             # 基础 UI 组件
│   ├── game/           # 游戏业务组件
│   └── layout/         # 布局组件
├── views/              # 页面视图
├── stores/             # Pinia 状态管理
├── services/           # 业务服务层
├── utils/              # 工具函数
├── types/              # TypeScript 类型定义
├── assets/             # 静态资源
│   └── configs/        # JSON5 配置文件
└── locales/            # 国际化文案
```

服务层按功能模块划分为多个独立的服务文件，涵盖战斗、武学、队列、内功、生活技能、市场、经济等系统。这种分层架构将业务逻辑与视图展示分离，便于测试和维护。

## 快速开始

### 环境要求

- Node.js 18 及以上版本
- pnpm 包管理器

### 安装与运行

```bash
# 安装依赖
pnpm install

# 启动开发服务器
pnpm dev

# 构建生产版本
pnpm build

# 类型检查
pnpm build:check

# 代码检查
pnpm lint

# 代码格式化
pnpm format
```

### 开发规范

项目严格遵循以下开发原则：

- **KISS 原则**：保持简单，选择最直接的实现方式
- **组件化**：自封装所有组件，避免外部 UI 库依赖
- **类型安全**：禁止使用 `as any`、`@ts-ignore` 等类型断言
- **响应式设计**：适配不同屏幕尺寸，侧边栏在小于 1024px 时自动折叠
- **Composition API**：使用 Vue 3 的 Composition API 而非 Options API

## 实施路线图

### V1 阶段：核心系统

**优先级最高**：

1. **扩展成就系统**：新增5个阶段的里程碑成就，对应主线进度
2. **新增地点事件**：在关键地点添加主线剧情触发事件
3. **声望系统**：加入门派声望和江湖声望，影响剧情选择
4. **称号系统**：27个称号，每个阶段解锁对应奖励

### V2 阶段：深度整合

**优先级中高**：

1. **门派系统**：加入五大派选择，差异化武学
2. **绝学系统**：9种绝学，每种提供强力被动/主动技能
3. **青龙令牌系统**：3块碎片收集，触发最终剧情
4. **兵器谱系统**：完善兵器排名和奖励

### V3 阶段：高级功能

**优先级中**：

1. **多结局系统**：3条结局路线，不同奖励
2. **隐藏剧情**：身世之谜、九州鼎真相等
3. **武林大会**：年度活动玩法，排位赛机制
4. **门派战争**：周期性阵营对抗活动

## 世界观设定速览

- **时代背景**：明朝中叶，天下承平日久，江湖暗流涌动
- **武学上限**：低武/中武世界，最高境界是「飞花摘叶皆可伤人」
- **五大派**：少林（刚猛霸道）、武当（以柔克刚）、峨眉（灵动飘逸）、华山（奇险快绝）、丐帮（人数众多）
- **核心冲突**：二十年前「沈百万之死」的惊天阴谋，玩家为父报仇的「真相之路」
